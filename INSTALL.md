# opencv-proto installation

Python `pip` package is required to install `opencv-proto`.

## From sources

Use the following command line to install `opencv-proto` from sources directory (containing `pyproject.toml`):

```shell
pip install .
```

## From PyPI

Alternatively you can install `opencv-proto` from PyPI:

```shell
pip install opencv-proto
```

To install it with third-parties (`opencv-python`, `colorhash`):

```shell
pip install opencv-proto[all]
```

Use `-U` flag for upgrade:

```shell
pip install -U opencv-proto
```
